# تکلیف‌یار | TaklifYar

اپلیکیشن اندرویدی مدیریت تکالیف مدرسه با رابط فارسی و حالت تیره.

## ساختار
- `app/src/main/assets/`: رابط HTML/CSS/JavaScript آفلاین
- `app/src/main/java/ir/taklifyar/app/MainActivity.java`: پوسته اندروید و انتخاب فایل
- `.github/workflows/build-apk.yml`: ساخت APK در GitHub Actions

## ساخت APK در GitHub
1. یک مخزن جدید در GitHub بساز.
2. تمام محتویات پوشه `تکلیف یار` را (نه خود پوشه به‌عنوان یک زیرپوشه اضافی) در مخزن بارگذاری کن.
3. به زبانه **Actions** برو و workflow با نام **Build Android APK** را باز کن.
4. پس از اجرای موفق، پایین صفحه اجرا در بخش **Artifacts** مورد `taklif-yar-debug-apk` را انتخاب و ZIP آن را دانلود کن.
5. ZIP را استخراج کن؛ فایل `app-debug.apk` داخل آن است.
6. APK را به گوشی منتقل و نصب کن. اگر Android اجازه داد، برای برنامه مدیریت فایل گزینه نصب برنامه‌های ناشناس را فعال کن.

## ساخت محلی (اختیاری)
با JDK 17، Android SDK Platform 35 و Gradle نصب‌شده:
`gradle assembleDebug`
خروجی: `app/build/outputs/apk/debug/app-debug.apk`

## نکات
- اطلاعات در فضای محلی WebView ذخیره می‌شود و برای استفاده روزانه اینترنت لازم نیست.
- حذف برنامه یا پاک‌کردن داده‌های آن ممکن است تکالیف را حذف کند؛ مرتب فایل JSON پشتیبان بگیر.
- فایل پشتیبان فقط از داخل خود برنامه و پس از اعتبارسنجی بازیابی شود.
- این پروژه به‌صورت اولیه آماده شده است؛ ساخت و آزمایش نصب APK باید در GitHub Actions و دستگاه واقعی تأیید شود.
